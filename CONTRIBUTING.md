# Contribution Guidelines

To practice proper Git workflow, please follow these rules:

1. **Do not commit to `main` directly.** Always create a feature branch (e.g., `feature/ch1-nouns` or `fix/typos`).
2. **Commit Messages:** Use clear and descriptive commit messages (e.g., `docs: complete chapter 1 exercise 2`).
3. **Pull Requests:** Open a PR against `main` and request at least one teammate to review your changes before merging.
